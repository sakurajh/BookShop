## 📦 获取源码

完整工程打包在仓库根目录的 **`version11.zip`** 中：

```text
1. 下载并解压 version11.zip
2. 用 Visual Studio 打开解压后的解决方案（.sln）
3. 直接 F5 运行
```

> 运行环境：Windows + Visual Studio 2019/2022；如涉及数据库，请先按工程内配置还原数据库。
